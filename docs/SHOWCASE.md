# 参赛 HTML 研究工作台

双击仓库根目录 `Open-Showcase.cmd`，或用浏览器直接打开 `results/index.html`。
不需要安装依赖、联网或 API Key。HTML 内嵌展示数据及五幅报告图，单文件约 4.9 MB。
如需 HTTP 预览，仍可使用 `python scripts/serve_results.py`（端口 8788）。

## 展示内容

按仓库内 SocioVerse2 dashboard 的模块组织为七页：研究概览、环境设定、模拟人群、
数据资源、实验与结果、研究报告、参考文献。统一顶部情景选择器，在各模块间保留选择。

- 环境页展示原帖、实验性政府回应、判断对象和事件时间轴；材料哈希与全部 54 组冻结输入匹配。
- 人群页展示合成属性分布、搜索名单和个人资料卡，可跳转到同一 Agent 的实验轨迹。
- 数据页提供四类数据表的分页预览、搜索和导出。
- 报告页按文档顺序提取最新用户编辑 DOCX 的段落和表格，目录可跳转。
  网页不是 Word 排版的复刻，公式和图片位置以下载原稿为准。DOCX 未修改。
- 文献页保留原报告五条书目，明确标识外部文献与项目材料；本次没有独立重验外部文献。

- V7 已完成的 54 组条件，可通过 RT / TC / GC / DGC 切换。
- 300 人状态矩阵、0—10 轮回放、1× / 2× / 4× 速度与累计接触人数。
- 个体评分、首次接触记录、合格更新与右删失状态。
- 两组相信人数曲线、TBU_FB / 合格更新人数 / 右删失人数对比。
- 按编号筛选情景，导出当前情景 3,300 行轨迹或筛选后的汇总 CSV。
- 来源文件、SHA-256、当前情景 provenance 和报告入口。
- 指标可切换三类状态、相信人数、已评分者平均分、累计接触；人群可切换全体、圈内、圈外。
- 五幅现有报告图内嵌，支持点击放大与 Escape 关闭。

当前数据来自 `results/v7_20261030`，不是新的模拟。原 V5 页面逐字节保留于
`results/legacy-v5.html`。单独复制 HTML 时核心交互仍可运行；来源文件和报告链接
需要保留原 `results` 目录结构。历史 V5 页面仍需 HTTP 服务器读取外部 JSON。
本次重构前的首版 HTML 保留于 `results/showcase-v1.html`，模板保留于
`scripts/showcase/v1.template.html`。

矩阵不是网络图；未加入未经核验的传播边。评分空值保持空缺。
已发布归档不含逐轮阅读正文、模型评论/转发文本与输出理由，个体页明确标出缺口。
环境页的网络图片是原报告的模型接触示意，不是实际传播路径。
个体详情中的首次接触和 FB 状态基于完整轨迹，回放轮次旁的状态与累计接触数才是当轮数据。
合成背景字段不是真实个人经历。不同 RT 的观察窗口不同，TBU_FB 均值不能单独作为效果排名。

## 维护

在仓库根目录执行（Python 标准库即可）：

```sh
python scripts/build_showcase.py
python scripts/verify_showcase.py
```

页面模板为 `scripts/showcase/index.template.html`；新增模块逻辑与样式分别为
`scripts/showcase/workbench.js` 和 `workbench.css`。材料加载器是 `scripts/showcase_assets.py`。
不要直接编辑生成的 `results/index.html`。
生成器读取四份已发布 CSV，检查 178,200 行的主体和轮次唯一性、评分分类、
1,782 条分组统计、累计接触人数、FB 均值和删失人数，然后嵌入压缩 JSON。
出现不匹配会停止，不会用示意数据补齐。原实验数据与模型代码均不修改。

界面采用原生 HTML/CSS/JavaScript，无 CDN、第三方字体或运行时网络数据请求。
支持窄屏布局、键盘操作、减少动画偏好和浏览器打印。

## 本次验证

- 数据校验：178,200 条状态、1,782 条分组汇总、FB 均值与删失、300 人资料对应、54 组冻结输入哈希。
- 浏览器：七页切换、情景与环境联动、用户搜索与轨迹跳转、轮次和指标切换、分页/搜索、报告目录、文献筛选、图表弹窗。
- 390px 视口：七页均无页面横向溢出；控制台未发现 JavaScript 错误。
- 内置浏览器限制 file://，视觉和交互验证使用 localhost；离线兼容通过内嵌资源与零 fetch 结构检查。

## 中英文界面 / Bilingual interface

页面右上角可切换中文与 English；浏览器允许本地存储时记住语言选择。导航、指标解释、动态状态、表格表头、提示和图表标签跟随切换，所选情景与回放轮次保持不变。翻译字典位于 `scripts/showcase/i18n.js`，构建时内嵌，不依赖在线翻译服务。

原始材料、人物背景、报告正文、书目信息和图片内文字保留原语言；页面明确标注这一范围。源数据字段与下载的原始记录保持不变。

验证：中英文往返切换、英文刷新记忆、情景切换、末轮回放动态文案、数据筛选（A0001 共 11 条）、390px 视口无横向溢出，以及原有 178,200 条状态数据校验。
