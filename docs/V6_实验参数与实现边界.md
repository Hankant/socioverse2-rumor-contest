# V6 实验参数与实现边界

更新日期：2026-10-20。

## 版本范围

本文记录独立本地 V6 开发版本的参数实现情况。**本次同步仅添加说明文档，不代表仓库 `app/` 已升级为 V6。** 仓库现有 `app/` 与 `results/completed_run/` 仍对应此前 V5 技术下线版本及其40轮完成结果。不得用本文的 V6 配置解释那次 V5 结果，也不得直接把下面的配置交给未升级的 `app/run.py`。

本地 V6 已改为每次10轮，政府分别在第2、5、8轮介入，构成三个独立实验条件；不是同一实验介入三次。此修改后的51项离线测试通过，但三个条件尚未完成真实 LLM 实验。

## 参数对应表

| 研究设置 | V6配置字段 | 可调范围或示例 | 当前实现与限制 |
|---|---|---|---|
| 圈内外相信程度差异 | `pbd` | 0、0.2、0.4 | 仅作用于规则用户，同时改变 PB 与 RC；未实现 LLM 圈内外初始相信程度差异 |
| 总轮数 | `--steps` | 本方案10 | Python入口及启动脚本默认10轮；结果校验读取实际配置轮数 |
| 政府介入时间 | `government_tick` | 2、5、8 | 控制纠正内容发布和一次性直接投放时间 |
| 接收者中圈内用户比例 | `targeting_inside_ratio` | 1、0.5、0 | 分别为全部圈内、一半圈内、全部圈外；按圈内身份选人，不筛选是否已经相信 |
| 直接投放人数 | `government_reach` | 当前40 | 不重复抽取；人数不足或比例无法对应整数人数时报错，不静默减少 |
| 个体政府信任组均值 | `government_trust_mean` | 0.75、0.5、0.25 | 规则用户用于个体GT抽样；LLM用于提示词中的政府来源评价，不能当作实际接受率 |
| 个体政府信任分布尺度 | `government_trust_sd` | 当前0.10 | 使用对称截断正态分位点；截断后实际标准差可能小于该值 |
| 投放随机种子 | `government_target_seed` | 当前20261019 | 固定条件可重建名单 |
| 信任分配随机种子 | `government_trust_seed` | 当前20261022 | 跨均值水平保持个体相对排序 |

`targeting_inside_ratio=null` 时沿用 `strategy`（inside/outside/random）。设为数值时，该比例优先，`strategy` 不再决定投放名单。“随机投放”不等于“50%圈内”。

`government_trust_mean=null` 时沿用规则用户固定 `gt=0.6` 与 LLM 原合成资料中的政府来源评价。设为数值时，为所有用户分配个体值，分别保证规则组和LLM组的均值，覆盖上述默认值。直接纠正与转发纠正均采用对应用户的GT或来源评价。

当前圈内只有82人，因此不能同时要求“100名不同接收者”和“100%圈内”。若保持40人投放，比例1、0.5、0分别对应圈内/圈外人数40/0、20/20、0/40。

## PBd目前实际做了什么

| PBd | 圈内PB | 圈外PB | 圈内RC | 圈外RC |
|---:|---:|---:|---:|---:|
| 0 | 0.579 | 0.579 | 0.100 | 0.100 |
| 0.2 | 0.679 | 0.479 | 0.117 | 0.083 |
| 0.4 | 0.779 | 0.379 | 0.135 | 0.065 |

PB是符合规则时的相信概率，RC是符合条件后的转发概率。以上是采用的表格值，不是本次实验估计值。

所有用户初始仍为 `unjudged`，不是按PB预先抽取相信者。因此不能把 `pbd` 称为已经实现的“全体用户初始相信比例差”。LLM合成角色具有不同分享倾向、核实偏好与来源评价，但没有将PBd映射为LLM两组的初始相信差异。该部分仍需单独定义、实现和验证。

## 配置示例

以下是V6条件配置片段，不是包含模型、服务地址与预算的完整配置：

```json
{
  "pbd": 0.2,
  "government_tick": 5,
  "government_reach": 40,
  "targeting_inside_ratio": 0.5,
  "government_trust_mean": 0.75,
  "government_trust_sd": 0.1,
  "government_target_seed": 20261019,
  "government_trust_seed": 20261022
}
```

这表示第5轮向20名圈内、20名圈外用户投放；两类决策用户的政府信任均值分别为0.75。它不意味着75%的LLM必然接受纠正。

本地V6提供 `minimax.tg2.config.json`、`minimax.tg5.config.json`、`minimax.tg8.config.json`。其他条件保持相同，在V6代码目录分别使用：

```powershell
.\Start-V6.ps1 -GovernmentTick 2
.\Start-V6.ps1 -GovernmentTick 5
.\Start-V6.ps1 -GovernmentTick 8
```

以上为三个独立启动命令，应按计划依次执行，不是自动批量运行指令。本仓库本次没有同步这些V6启动文件。

## TBU与观察窗口

- 第2轮介入：观察人群为第1轮结束时的相信者，等待时间为首次转为reject的轮次减2。
- 第5轮介入：观察人群为第4轮结束时的相信者，等待时间减5。
- 第8轮介入：观察人群为第7轮结束时的相信者，等待时间减8。

介入当轮转变计0；截至第10轮未转变者不进入完成者平均TBU，必须另报人数。无完成者时平均值缺失，不能填0。

三个条件的介入后观察窗口不同，观察人群也可能不同，不能只用完成者平均TBU排名。固定种子保持部分随机输入一致，但不保证LLM回答相同，也不自动保证干预前状态相同。

## 尚未完成与解释边界

1. 四个三水平因素在设计上构成81个组合，但其中PBd尚未完整作用于LLM，不能声称四因素已经完整操作化。
2. 81个条件没有自动执行；每个条件一次运行也不等于随机稳定性检验。
3. 合成个体参数与经历不是原始账户资料中测得的真实心理属性；均值、尺度与分配规则属于实验设定。
4. 总轮数改为10没有同时按比例缩放帖子有效期、重读间隔、政府接触人数等规则。
5. 不得将暂停中的旧40轮结果拼入新10轮条件。续跑要求代码、输入、配置与总轮数一致。
6. 本文描述实现范围，不代表已验证真实平台拟合或现实政府辟谣效果。
