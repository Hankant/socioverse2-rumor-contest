# 数据使用与脱敏

原始资料包含公开账号派生信息，但未核实再分发许可。本仓库不上传原账号资料、来源行号、个人所在地、原精确账户统计、完整prompt/记忆、原始审计文件或DuckDB。

演示人口：保留582个假名ID、组别、角色分配；其他字段清空，部分计数字段按ID确定性生成，不对应真实账号。事件与政府纠正文本为模拟刺激，尤其纠正不是已核实的真实官方通告。

历史结果：仅发布聚合指标与结构化行动字段。原始哈希用于溯源，不代表原输入已包含。本项目没有因此声称取得伦理审批、原账号授权或完成现实验证。

共享范围：代码供参赛审查和授权协作。尚未给原创代码选择额外开源许可证；第三方组件遵守各自许可证。受限原始数据不得通过PR添加。
