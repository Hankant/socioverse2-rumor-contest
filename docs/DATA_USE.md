# 数据使用与公开范围

项目所有者明确要求公开模型实际账号资料与完整审计，本次在公开GitHub仓库增加research_archive。该请求不是对平台再分发条款或参与者授权的独立核验，也不代表伦理审批。

## 两套输入

materials：合成演示人口，保留ID、组别和决策模式，其他资料清空或确定性生成。
research_archive/inputs：历史实验实际冻结材料。582个agent、305个Pxxxx账号资料关联，包含原实际性别、地区、关注/粉丝/发帖数量和来源行号。部分关联字段为空。未添加昵称、真实平台ID、联系方式等不存在于运行表中的字段。这不是原始整份采集Excel。

## 完整审计

research_archive/audit保留所有实际提示词、个人记忆、展示内容、原始回答、缓存、错误、阶段日志和预算。其用途是审查运行过程。自由文本是模型生成内容，不是原账号真实发言；实验纠正文本不是核实过的官方通告。

凭据与认证头不发布。绝对路径如存在会替换并登记。EXPORT_MANIFEST包含原文件与发布文件哈希，便于核查未改动内容。未上传原DuckDB二进制；已提供全部40轮检查点及审计文本。

资料公开不赋予新的数据使用许可，合作人不得将假名资料与真实账号重新关联。原创代码尚未指定额外开源许可证；第三方SocioVerse2保留Apache-2.0及NOTICE。
