# 最新异质人群版V6：用户手动运行

适用于当前本机部署，版本 `v6-network-thread-all-conditions-20261022-1`。
初始82名SOURCE关注者接触原帖；其他人通过关注账号转发首次接触，接触后可每轮阅读完整先前评论，未接触者不提前获得内容。官方仍为独立账号；11项个人条件必须逐项输出应用摘要。以 [网络触达与完整评论](V6_网络触达与完整评论.md) 为准。
已启用主/副MiniMax Key自动切换，凭据由Windows当前用户加密保存。详细规则见 [V6_API主副切换与密钥管理.md](V6_API主副切换与密钥管理.md)。
当前LLM按完整说法评分>50记相信、<=50记不相信，50归不相信；评分二分类规则见`V6_评分二分类规则.md`。
本说明中的真实命令每执行一次，都新建一组实验。不要同时使用双击和命令行两种入口，不要重复启动。

## 1. 最简单的入口

打开部署文件夹：

```text
E:\papers\socioverse 2026\socioverse2_v6_local
```

双击 `Run-V6-Heterogeneity-Test.cmd`。当前默认读取本机加密保存的主/副Key，无需再次输入，直接开始本组实验。后续更换Key请使用专门的隐藏输入命令，不要写入源码或普通配置。

这个入口只运行D040/T02/C080/G075一组、10轮，API并发上限2。它不会调用54组批量启动器。

## 2. PowerShell运行方法

如果采用本方法，就不要再双击上面的启动器。打开PowerShell，先逐段执行：

```powershell
Set-Location -LiteralPath 'E:\papers\socioverse 2026\socioverse2_v6_local'
$env:PYTHONIOENCODING = 'utf-8'
```

先做不调用API的预检：

```powershell
.\.venv\Scripts\python.exe app_v6/local_cli.py preview --gap 0.4 --tg 2 --target 0.8 --gt 0.75 --steps 10 --concurrency 2
```

再执行真正运行的命令（下面是一整行）：

```powershell
.\.venv\Scripts\python.exe -u scripts/run_live_checked.py --gap 0.4 --tg 2 --target 0.8 --gt 0.75 --steps 10 --concurrency 2
```

当前保存密钥模式不再单独发启动认证请求，第一条正式请求同时检验认证，并按同一逻辑自动切换。若改回 `api_key_mode=environment`，才会出现原有隐藏输入和小型认证检查。加密文件由Windows DPAPI保护；解密后的Key只在进程内使用。

启动时应显示 `ONE condition, 10 rounds`、`version=v6-shared-thread-all-conditions-20261022-1`、`API concurrency cap=2`，以及 `Using encrypted local MiniMax keys`。每次请求末尾 `key=primary` / `key=backup` 表示实际使用的槽位，不显示密钥。

`LLM request ... tick=... agent=...`表示请求开始，不等于已经成功；完整轮次以status.json的last_completed_tick为准。

## 3. 本次参数

| 参数 | 值 | 含义 |
|---|---:|---|
| --gap | 0.4 | 圈内/外SOURCE初始信任均值差；均值0.7/0.3，不是相信比例 |
| --tg | 2 | 第2轮一次性政府介入 |
| --target | 0.8 | 100名直接接收者中80名圈内、20名圈外，不筛选是否相信 |
| --gt | 0.75 | 政府信任均值 |
| --steps | 10 | 本组10个时间步 |
| --concurrency | 2 | API并发上限，实际可自适应下降；不是同时运行2组 |

当前仍为305名LLM用户＋277名规则用户；新增年龄、合成地区、职业和MBTI背景。MBTI、人口占比属于合成实验假设。规则用户的属性不进入原概率公式。

本组输入保护32768代理token、最近5次完整经历和全部可见评论不裁剪；每次最大输出1536 tokens，输出预算按1536预留。全评论增长可能触发输入保护；4次回答仍无法满足逐项条件合同则暂停整轮。

## 5. 结果在哪里

```powershell
$runInfo = Get-Content -LiteralPath '.\runs\v6\latest.json' -Raw | ConvertFrom-Json
Invoke-Item -LiteralPath $runInfo.run_dir
```

| 文件 | 用途 |
|---|---|
| 实验参数.md / experiment_parameters.json | 本次实际使用的参数 |
| status.json | 状态与最后完整轮次 |
| trajectory/metrics_history.json | 已完成轮次的相信、不相信和未判断等汇总 |
| trajectory/belief_measurements.csv | 用户、时间步、MBTI、年龄地区职业、主观可信度及三个事实分项 |
| trajectory/condition_applications.csv | 每个已提交的LLM决策逐项记录11个条件如何影响评分、评论或转发 |
| trajectory/panel.csv | 每人每轮状态和行动详情 |
| reports/binary_results.csv | 最后完整时间步的二分类人数和相信率 |
| reports/report.md | 完成或正常暂停后的运行摘要 |
| provenance.json | 版本、输入哈希、配置目录和API审计目录 |

CSV通常在结束或程序正常处理暂停后导出。`belief_measurements.csv`包含初始step=0及逐轮记录；查看最终人数时应筛选最后完整step，不要把同一用户多轮记录相加当成人数。规则用户的主观评分为空白，不是0分。

完整结束后可执行校验：

```powershell
$runInfo = Get-Content -LiteralPath '.\runs\v6\latest.json' -Raw | ConvertFrom-Json
.\.venv\Scripts\python.exe app_v6/local_cli.py verify --run-dir $runInfo.run_dir
```

Verify只用于完整完成的运行，不能把暂停状态当成完成。

## 6. 停止与常见报错

要停止时，在运行窗口按一次Ctrl+C，等待程序写出状态、回到命令提示符，再关闭窗口。不要直接关闭运行窗口、强制结束Python或关机。

| 状态/错误 | 含义与处理 |
|---|---|
| HTTP 401 | Key或认证不通过，检查账户与Key；不在聊天中发送Key |
| HTTP 429 / paused_quota | 频率、token吞吐、订阅窗口或服务容量等限制；状态名不证明额度耗尽。程序会降速重试，耗尽后暂停 |
| paused_prompt_budget | 完整记忆超过输入保护上限，未静默删减；先保留记录，再决定是否调整执行上限 |
| interrupted | 程序中断，查看最后完整轮次和API审计，不能当成已完成 |
| pending_usage_unknown / UncertainRequest | 请求已发出但返回结果未知；不要删除审计或盲目重发，可能已消耗额度 |

当前手动启动入口已固定并发2。如希望对之后的新运行进一步降低并发，可把真实命令中的`--concurrency 2`改成`--concurrency 1`。这会改变执行速度，不改变四个研究因素；仍不能保证消除账户级限额。
