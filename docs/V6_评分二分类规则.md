# V6评分二分类规则

评分规则发布版本：`v6-binary-score-20261022-1`。当前运行版本为 `v6-shared-thread-all-conditions-20261022-1`，已新增全评论与逐项条件合同，评分规则不变。用户已确认：50分归为不相信。

## 分类规则

以LLM对完整核心说法给出的`subjective_credibility`作为唯一分类分数：

```python
def score_to_belief(score):
    if type(score) not in (int, float) or not math.isfinite(score) or not 0 <= score <= 100:
        raise ValueError("invalid belief measurement")
    return "believe" if score > 50 else "reject"
```

| 分数 | 分类 |
|---:|---|
| 0 | 不相信 |
| 49.999 | 不相信 |
| 50 | 不相信 |
| 50.0001 | 相信 |
| 100 | 相信 |

允许小数，按原始数值比较，不先四舍五入。缺失、布尔值、字符串、NaN、无穷大或超出0—100范围的分数会验证失败，按已有格式重试策略处理，不用0分填补，也不默认记为不相信。

## LLM现在提交什么

新Prompt不再让LLM选择相信、不确定、不相信三个标签。它只提交完整说法评分、三个分项评分、评论、转发和已接触内容ID。例如：

```json
{
  "subjective_credibility": 50,
  "component_credibility": {
    "funds_redirected": 45,
    "safety_delayed": 60,
    "causal_link": 40
  },
  "comment": {"enabled": false, "text": ""},
  "repost": {"enabled": false, "target_content_id": null, "text": ""},
  "evidence_ids": ["P001"]
}
```

程序会将这个例子的最终分类计算为`reject`。三个分项继续保留供检查，**不取平均值、不分别投票、不用它们替代完整说法评分**。

原始模型回答原样保存在审计记录中；派生后的`answer.belief`、当前状态、记忆、面板及导出使用同一条规则。即使模型额外返回了一个标签，程序也只按分数计算最终分类，不信任其独立标签。

当前初始来源信任、政府信任仍然是角色背景，不能直接复制为事实评分。年龄、职业、地区和MBTI分配保持。

## 未判断与统计分母

`uncertain`不再是新版运行的有效分类，新版逐轮指标没有`all_uncertain`、`llm_uncertain`或`remaining_uncertain`等字段。

尚未接触信息、尚未形成判断的角色仍保留技术状态`unjudged`。它不代表50分，也不代表不相信。请求失败不会制造分类。

最终相信率为：

```text
相信率 = 相信人数 / (相信人数 + 不相信人数)
```

初始未判断者单列为`unjudged_n`，不进入这个分母；如果一个人都没有判断，相信率留空/null，不填0。导出同时提供`population_n`与`judged_n`，避免把覆盖不足当作全体已判断。

## 混合模型边界

305名LLM角色按上述分数规则分类。277名规则角色原本直接按PB/RC/GT/RF抽样形成相信/不相信，本次保留这些公式；不给规则用户编造一份LLM评分。其评分仍留空，已判断后的分类同样只有相信或不相信。
