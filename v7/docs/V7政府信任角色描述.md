# V7政府信任的三类角色描述

运行版本：`v7-government-trust-persona-20261027-2`。策略：`government_trust_prompt_policy=individual_three_level_v1`。

本次将用户确认的较高、中等、较低政府信任描述写入每名用户的稳定个人资料，使模型在看到实际信任数值的同时，收到相应的日常角色态度。原有持续信念更新、实际接触次数和相信转不信记录继续生效。

## 实际提示文案

| 政府信任程度 | 写入该用户资料的描述 |
| --- | --- |
| 较高 | 你通常认为政府较专业、发布信息较可靠，愿意给予官方回应较高权重。 |
| 中等 | 你对政府有一定信任，但是否接受回应，取决于其具体解释与当前可见材料。 |
| 较低 | 你对官方自述较谨慎，仅凭官方身份或一句否认较难改变原判断，但仍会考虑具体核查材料。 |

每次只写入该用户所属档次的文案，不把三档全部交给每个用户自行选择。

文案前包含本人的实际政府信任值，保留6位小数用于阅读；原始数值仍完整保存在输入资料和条件表中，程序不按显示小数重新分档。文案后补充：

> 本实验分配覆盖资料表默认政府倾向。保留本人的具体信任数值，同档用户也可有不同反应。这是角色态度，不保证本次官方回应必然正确。只有实际读到官方回应后，才结合上次信念分和当前已见材料判断是否接受；未读时不能预知回应内容或结论。

## 怎样分档

根据**每名用户实际分配到的政府信任值g**，采用0—1尺度的三等分约定：

- `0 <= g < 1/3`：较低。
- `1/3 <= g < 2/3`：中等。
- `2/3 <= g <= 1`：较高。

例如，实际值0.25对应较低，0.50对应中等，0.75对应较高。恰好1/3属于中等，恰好2/3属于较高。

这两个分界是本次实现采用的合成措辞约定，不是经公众调查得到的分类界限。可在`app_v7/government.py`的`government_trust_role`中审查。若以后调整分界，应保存为新的提示词版本，不应改动正在运行实验的设定。

实验组的0.25、0.50、0.75是群体均值。个体存在离散程度，因此同一组里可能出现相邻档次。程序依据个体值选择文案，不直接把整个0.75组全部标为较高，也不会把个体信任改成档次代表值。

## 进入模型的实际位置

`llm_client.render_prompt`生成个人资料时，使用实际分配的政府信任值，更新：

- `government_prior`：本人实际信任值，保持原值。
- `synthetic_government_evaluation`：上述数值、所属档次、对应角色描述和接触边界。
- `government_trust_level`：较高、中等或较低。
- `government_trust_description_policy`：本次描述策略标识。

这些字段位于`稳定个人资料 → 合成角色设定_不是真实账户事实`。完整发送、精简发送、共享前缀精简发送三种格式都保留同一描述。具体连续信任值仍作为原11项条件中的`government_trust`输入；条件引用也标识本次描述策略，避免新旧提示被当成相同上下文。

现有来源权重说明继续要求：实际读到官方否认后，政府信任较高通常增加接受其核查与否认的倾向，并相应降低对原始资金调整说法的评分。对博主的信任、反复接触、核验偏好和其他个人条件仍参与综合判断。

本次只加强政府信任的角色表达，没有新增自动扣分，没有更改博主来源信任的分配与描述机制，也没有预设转变人数或TBU。LLM仍自主返回0—100分，程序按`>50`相信、`<=50`不相信分类。

## 实现与验证

文案和分档集中在`app_v7/government.py`。`experiment.py`启用新策略，`run.py`和`model.py`将策略传递到观察，`llm_client.py`写入个人资料。`local_cli.py`生成预览，`parameter_report.py`将分档约定写入新运行的设定报告。

离线测试核对三档边界、非法数值、三种实际发送格式、个体值与群体均值的区别、官方内容未提前展示、旧描述兼容和连续评分保留。测试只验证实现与输入，不证明新文案更接近真实公众或必然缩短TBU。
